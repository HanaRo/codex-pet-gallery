# v1.0.0 · DeepSeek-chan Classic

[简体中文](v1.0.0.md) · **English** · [GitHub Release](https://github.com/HanaRo/codex-pet-gallery/releases/tag/v1.0.0)

The first public release. The blue-haired maid blinks empty-handed at idle, runs in either direction when dragged, and eats rice from a bowl while you work.

## Downloads

- **[Codex desktop installer ZIP](https://github.com/HanaRo/codex-pet-gallery/releases/download/v1.0.0/deepseek-chan-1.0.0-pet.zip)** with `pet.json`, the sprite sheet, the layout, and installation instructions.
- **[ChatGPT Work import PNG](https://raw.githubusercontent.com/HanaRo/codex-pet-gallery/v1.0.0/pets/deepseek-chan/versions/1.0.0/spritesheet.png)** for a v2-compatible custom Pet entry point.

## Animation preview

<img src="https://raw.githubusercontent.com/HanaRo/codex-pet-gallery/v1.0.0/pets/deepseek-chan/versions/1.0.0/previews/states/idle.gif" width="128" alt="Classic edition blinking and breathing at idle">

She wags her tail while standing when you hover, holds a bowl while waiting, and eats rice while you work. The full atlas has 73 frames across nine animation states and 16 gaze directions. [All animations](https://github.com/HanaRo/codex-pet-gallery/blob/v1.0.0/pets/deepseek-chan/versions/1.0.0/previews/all-states.gif)

## Installation and compatibility

For desktop Codex, place `pet.json` and `spritesheet.png` in `<CODEX_HOME>/pets/deepseek-chan/` and select the pet in Settings → Pets. For ChatGPT Work, import the PNG through a v2-compatible entry point. [Installation guide](../INSTALL.en.md)
