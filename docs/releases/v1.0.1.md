# v1.0.1 · DeepSeek 娘干饭版

**简体中文** · [English](v1.0.1.en.md) · [GitHub Release](https://github.com/HanaRo/codex-pet-gallery/releases/tag/v1.0.1)

捧空碗等饭，被揪起来会晃腿摆尾。这个版本让待机、摇尾巴和扒饭都围绕同一只碗展开。

## 下载

- **[Codex 桌面安装包 ZIP](https://github.com/HanaRo/codex-pet-gallery/releases/download/v1.0.1/deepseek-chan-1.0.1-pet.zip)**，包含 `pet.json`、精灵图、布局和安装说明。
- **[ChatGPT Work 导入图 PNG](https://github.com/HanaRo/codex-pet-gallery/releases/download/v1.0.1/deepseek-chan-1.0.1-spritesheet.png)**，适用于支持 v2 的自定义 Pet 入口。

## 这次更新

<img src="https://raw.githubusercontent.com/HanaRo/codex-pet-gallery/v1.0.1/pets/deepseek-chan/versions/1.0.1/previews/states/idle.gif" width="128" alt="干饭版捧空碗等饭">

- 待机时捧空碗等饭，也会呼吸和眨眼。
- 左右拖动改为揪起后晃腿摆尾，站立摇尾巴时继续捧碗。
- 扒饭动作收小举筷幅度，对齐头发和鳍耳的比例。

[完整动作](https://github.com/HanaRo/codex-pet-gallery/blob/v1.0.1/pets/deepseek-chan/versions/1.0.1/previews/all-states.gif) · [经典版 1.0.0](https://github.com/HanaRo/codex-pet-gallery/releases/tag/v1.0.0)

## 安装与兼容

桌面 Codex 将 `pet.json` 和 `spritesheet.png` 放到 `<CODEX_HOME>/pets/deepseek-chan/`，再从 Pets 设置选择。ChatGPT Work 可使用支持 v2 的入口导入 PNG。[安装步骤](https://github.com/HanaRo/codex-pet-gallery/blob/main/docs/INSTALL.md)
