# v1.0.0 · DeepSeek 娘经典版

首个公开版本。蓝发女仆会空手眨眼待机、左右小跑，工作时端着碗扒饭。

- **[Codex 桌面安装包 ZIP](https://github.com/HanaRo/codex-pet-gallery/releases/download/v1.0.0/deepseek-chan-1.0.0-pet.zip)**，包含 `pet.json`、精灵图、布局和安装说明。
- **[ChatGPT Work 导入图 PNG](https://raw.githubusercontent.com/HanaRo/codex-pet-gallery/v1.0.0/pets/deepseek-chan/versions/1.0.0/spritesheet.png)**，适用于支持 v2 的自定义 Pet 入口。
