# DeepSeek 娘 · 装学霸版

DeepSeek 娘戴上眼镜和白龙假发，捧着书假装用功，书后藏着饭碗。工作时她会抬书挡住嘴偷吃，被鼠标揪起来时会晃腿摆尾，再伸手扶正滑落的假发。

当前版本为 [1.0.0](versions/1.0.0/)，采用摇尾巴配色修正后的图集。
