# DeepSeek 娘 1.0.1

2026-10-22 的已应用版本快照。精灵图与当前安装后重新下载的素材逐像素一致。

相对 1.0.0 更新 33 帧，涉及 idle、左右拖动、jumping（站立摇尾巴）和 running（扒饭）；其余 40 帧保留原像素，包括全部十六方向。

- idle：捧空碗等饭、轻微呼吸与完整眨眼。
- 左右拖动：像被鼠标揪起呆毛，悬空晃腿、左右摆尾并轻微晃动身体；左向由右向逐格镜像，保持帧序。
- 摇尾巴：沿用捧碗形象，尾巴从身后经过，在身体两侧交替出现。
- 扒饭：缩小举筷幅度，修正头发与鳍耳偏宽，角色宽 147–149 像素、高 191–192 像素，接近 idle 的 150×191；测量 alpha 阈值为 16。

frames.zip 保存最终 73 张无损 PNG，是精确重建的输入。sources/ 保存选用的原画、高清条带、提示词、拖动关键姿势、逐格镜像来源和一份最近的修改前 atlas。左向拖动条带为原生尺寸派生结果，高清来源是右向条带。qa/ 保存脱敏后的实际验证、注册参数、版本差异和安装后像素核对。

预览按已核查客户端的帧时长导出。各状态 GIF 为单行动作循环演示；客户端默认三轮后回到 idle 的行为另见 previews/transitions/running-auto-idle.gif。look-loop 是检查方向顺序的演示，并非客户端会自动旋转一圈。历史版本中的均匀速度预览保持原样。

仍保留的限制：方向注视及部分业务状态沿用旧版空手姿势，切换时碗可能消失；镜像拖动的抓取点可能在反向时横向跳动；客户端没有放下动画或过渡混合槽，素材不能改变三轮回落策略。详见仓库根目录的 docs/TRANSITIONS.md。
